# AWS EC2 Node.js Demo

Simple Node.js Express application deployed on AWS EC2 Free Tier.

I created a simple Node.js Express application and deployed it on an AWS EC2 Ubuntu instance. I installed Node.js, cloned the project from GitHub, installed dependencies using npm, and ran the server on port 3000. I configured EC2 security groups to allow inbound traffic and accessed the application using the EC2 public IP

## Endpoints
- `/` → Hello message
- `/health` → Health check
